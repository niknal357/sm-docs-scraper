# HTML output review

## Scope

- Reviewed all **154 HTML pages** and inventoried all **165 emitted support files** under `dist/html/`.
- Rendered every HTML page in Chrome at 1440 × 1000 and 390 × 844.
- Checked local links, fragments, resources, duplicate IDs, document overflow, navbar overlap, sparse pages, titles, breadcrumbs, and obvious malformed text.
- Ran the browser search and `node tests/search_quality.js` successfully.

## Main findings

- **Two pages look broken:** both `sm.debugGui.html` pages contain only an H1.
- **Several Terrain pages look like placeholders:** three namespace pages and five userdata pages have almost no content.
- **The Shape userdata page contains visibly malformed prose** in three repeated parameter descriptions.
- **Empty TOC rails waste 220 px** on 31 desktop pages, including templates, indexes, sparse pages, and Search.
- **Template and index navigation is weak:** template pages feel orphaned, while environment/category indexes have no active sidebar item.
- **Titles leak generated names:** template tabs/breadcrumbs show `-Template`; four index tabs show raw hyphenated directory names.
- **Metadata casing is awkward:** 33 userdata pages say `Server And Client`.
- **Shared behavior was otherwise solid:** no broken local links/fragments/resources, duplicate IDs, horizontal page overflow, or navbar collisions were found.
- **All pages emit a blank `data:,` favicon**, so browser tabs have no recognizable site icon.
