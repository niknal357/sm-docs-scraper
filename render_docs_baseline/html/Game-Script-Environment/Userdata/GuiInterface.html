GuiInterface

Usage: Client Only

Serializable: No

A userdata object representing a GUI interface.

A gui interface is an adapter between a script and a GUI.

Can only be used on the client.

Operations:

Operation Returns Description
GuiInterface == GuiInterface boolean Checks if two instances of GuiInterface refer to the same GuiInterface.

Client-only
